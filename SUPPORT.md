# Support

Gnostoa is a pre-release project maintained on a best-effort basis. There is
**No support SLA**, paid support channel or production-operations commitment.

## Where to ask

- Use [GitHub Issues](https://github.com/ktogias/gnostoa/issues) for
  reproducible defects, documentation problems and bounded usage questions.
- Use [CONTRIBUTING.md](CONTRIBUTING.md) for proposed source changes.
- Use [SECURITY.md](SECURITY.md) for vulnerabilities; do not publish sensitive
  security details in an Issue.

Before opening an Issue, search existing Work Items and include:

- the exact Gnostoa revision or released version, if one exists;
- operating system, Python version and native or container route;
- the complete command and a minimal anonymous fixture;
- expected behavior, observed behavior and the smallest reproducible output;
  and
- any local changes, while removing credentials, private paths and project
  data.

## Current boundaries

The maintained evaluation surface is the source quick start, validation,
policy checks and bounded context-pack generation documented in the README.
Open research Work Items are not promises of implementation or support.
Repository publication will not by itself make the source production-ready or
create compatibility, migration, availability or response-time guarantees.
