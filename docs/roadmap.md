# Implementation roadmap

This MkDocs page is a derived navigation projection. The canonical toolkit
roadmap is [Toolkit evolution](../knowledge/lifecycles/toolkit-evolution.md).

Adopting projects progress independently through:

- [existing-project adoption](../guidance/workflows/adopt-existing-project.md);
- [project/module specialization](../guidance/workflows/create-specialization.md);
- [tool selection by measured need](../guidance/reference/tool-selection.md).

Optional retrieval or catalog layers are promoted only when measured benefit
exceeds their generation, review and operating cost.
